# favicon を決めた過程（2026-10-21）

**いまの favicon は M1。** ユーザーの言葉で「一旦 M1 で進めよう。完成を見てまた変えるかもしれない」。
変えるときに同じ所から考え直さずに済むよう、候補と、各回で何を選び何を注文されたかを残す。
候補の SVG は全部 [`docs/design/favicon/`](./favicon/) にある（ファイル名は下の表の記号と同じ）。

## 前提

- 以前の favicon は紫の電子回路と十字の絵（`app/icon.png`）で、デザイン刷新（#129）後の配色と合っていなかった（ユーザー報告）
- サイトの色：背景 `#11161d`・青 `#5ab0ea`・文字 `#0b1218`（青の上）。ロゴの英字は Rajdhani（角ばった書体）
- 16px（タブ）・32px（高精細のタブ）・180px（スマホのホーム画面）で見え方を比べた。16px ではどの案も細部が潰れる

## M1 の中身

- 背景：右上から青い光が差す濃紺（グループ画面の「遊んだ時間」の帯と同じ光の差し方）
- 奥の2枚：扇に広げた板（「積み重ね＝Staq」と「みんなに広げて渡す＝Share」）
- 手前の板：青のグラデーションで、後ろをぼかして光らせ、縁を白く光らせる（L4 のネオン感）
- 「S」：ロゴの Rajdhani に寄せた、まっすぐな線と小さな角丸の角ばった S

## 置き場所

| ファイル | 用途 |
|---|---|
| `apps/web/src/app/icon.svg` | ブラウザのタブ（Next.js が `<link rel="icon" type="image/svg+xml">` を出す）。`docs/design/favicon/m1.svg` と同じ |
| `apps/web/src/app/apple-icon.png` | iPhone のホーム画面（180px）。iOS が角を丸めるので、背景の角丸を外した形から書き出した |
| `apps/web/public/favicon.ico` | SVG を読まないブラウザ用（16・32・48px の PNG を入れた ICO） |

**作り直すとき**は、`docs/design/favicon/` の SVG を直してから上の3つを書き出し直す。PNG と ICO は SVG を Chromium で
その大きさに描いて書き出した（16・32・48・180px）。`public/icon.png`・`public/logo.png` はコードから参照されていないので触っていない。
